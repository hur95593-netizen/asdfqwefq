# asdfqwefq



帮我开发一款「HTML Demo → 前端需求说明文档」的 Skill，需要从架构设计、标准工作流、需求提取维度、技术实现要点、输出规范、避坑方案、完整性验证六个维度系统设计。细化要求如下：

1、输入材料是一个文件夹目录，里面可能是有多个 html 作为入口的，即并非是 SPA 页面。也可能是一个 SPA 页面，通过 React / VUE 编写的 demo 页面，只有一个入口。

2、输入材料中可能包含“交互说明文档”，可能是 md、txt、html 格式，里面会有一些交互细节逻辑补充和需求补充。而需求补充中，可能会出现 “复用 xxx 模块” 这样的字眼，如果有这样的字眼的话说明了 “xx 模块 “ 就不需要创建新模块代码了，也就是不需要纳入到输出的需求说明文档 md 中。

3、输入材料中文件中可能有硬编码一些 mock 数据，那么这些数据我希望到时候也能备份下来作为输出后的需求文档 md 来参考。

4、skill 提速要求：分析整个任务中哪些任务是可以并行执行的，若有，就启动多个 subagent 去执行来提升速度。
