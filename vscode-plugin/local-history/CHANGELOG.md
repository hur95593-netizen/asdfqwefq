# 更新日志

## 1.0.0

首个版本，覆盖需求文档中 v1.0 / v1.5 / v2.0 三个里程碑的全部功能点。

### 自动快照
- 保存、编辑停顿、关闭标签页、外部变更、创建、删除、重命名七类触发
- 空变更过滤、防抖合并、大文件降频、二进制文件跳过

### 历史面板
- Webview 时间轴 + VSCode 原生 diff 双栏
- 内容搜索、标签筛选、时间筛选、对比方向切换
- 两个历史版本互相对比
- 右键菜单：还原 / 片段恢复 / 标签 / 导出 / 删除

### 侧边栏
- File History、Recent Changes、Deleted Files 三个视图

### 恢复
- 全文件还原（自动备份当前内容）
- 变更块多选恢复、选区恢复
- 已删除文件恢复
- 工作区时间点回滚

### 存储
- blob 内容哈希去重 + gzip 压缩
- 原子写入，索引与元数据损坏自愈
- 保留天数 / 单文件版本数 / 总大小三级清理，孤儿 blob 回收
- 存储统计与管理界面
- 可选的 AES-256-GCM 加密存储
